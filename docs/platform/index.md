## Platform overview

The Commerce Integration Platform consists of several integrated components that support partner integrations and day-to-day platform operations.

Core capabilities include:

- Browser-based operations console
- REST API for partner integrations
- Product feed ingestion and ETL processing
- Partner, product, customer, and order management
- Webhook subscription and delivery tracking
- Operational dashboards and analytics
- Cloud infrastructure hosted on AWS
- Comprehensive platform documentation
